Windows

Install in Three Steps

  1. Extract the zipRight-click the downloaded zip and choose Extract All…, then open the folder it makes.
  2. Copy CosmicShore.scr into C:\Windows\System32Windows asks for administrator permission: click Continue. Screen Saver Settings only lists screensavers kept in that folder. Right-click → Install from anywhere else picks it once, but it drops out of the list as soon as you choose another.
  3. Choose it in Screen Saver SettingsOpen Start, type screen saver and open Change screen saver. Pick Cosmic Shore, set the wait time and click OK.

“Windows protected your PC”

This early build is not code-signed yet, so Windows shows a blue warning the first time it runs. Click More info, then Run anyway. Some antivirus programs are wary of unsigned screensavers too. A signed build comes later, and the warning goes away with it.

Quick Answers

Good to Know

Do I need the game installed?

No. The screensaver is a separate download that runs on its own: no game, no account and no internet. It sends nothing anywhere.

Can I try it without installing?

Yes. In the extracted folder, right-click CosmicShore.scr and choose Test. Move the mouse or press any key to leave. Double-click it to open its settings.

What can I change?

In Screen Saver Settings, click Settings… to choose the frame rate, which screens it runs on, the wide or close-up camera, and the colour set (any of the game's own).

Will it drain my battery or slow my PC?

It is built to be light. It draws 30 frames a second by default, uses the power-saving graphics chip where there is one, and stops when you come back.

It says WebView2 is missing.

The screensaver draws with Microsoft Edge WebView2, which comes with Windows 11 and nearly every Windows 10 PC. If yours is missing it, the screensaver offers Microsoft’s download page.

How do I uninstall it?

Pick another screensaver (or None) in Screen Saver Settings, then delete C:\Windows\System32\CosmicShore.scr. To remove its settings too, delete the Froglet\CosmicShoreScreensaver folders in %APPDATA% and %LOCALAPPDATA%.
